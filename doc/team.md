协作边界：

- VSCode 在 extensions/vscode-svg，DSH 在 integrations/dsh-svg，分别独立于 CLI 的运行边界。
- CLI 插件只调用公开 API；接口缺口必须以单独框架修订提交反馈，不暗改 box 或标签接入证明。
- box 的代码装配与配置装配从共同框架提交分出，既有 `final` 不移动。
- 各组员负责自己章节和演示，王以撒统一整合文档，避免多人同时改整份 README。
- 审核记录应包含 AI 建议、核查方法、发现问题及实际复验，不伪造他人作者身份或讨论。

建议各成员依次演示：原生 Outline 与 SVG、stats/dir、box 属性与回滚、两标签保存点、加载器失败恢复、DSH 四工具。完整流程可参照 doc/transcript 输入。
