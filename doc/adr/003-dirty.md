# ADR-003：内容 dirty、祖先传播和标签顺序

状态：采用。

dirty 按当前内容与保存基线不一致判断，不按“发生过编辑事件”判断。init/read/save 成功建立基线；save 失败不改变基线；canvas 修改不是保存，标记 SVG 根。

ModifiedStar 实例私有字段保存每个节点的递归指纹与画布指纹。新节点立即标星；子节点修改向祖先容器和根传播。undo 回到保存点后星号消失，redo 再出现。

多个标签严格按注册顺序拼接，默认组合为 `(box) *`。BoxTypeLabel 和 ModifiedStar 不互相依赖。禁用后基线渲染不增加任何字符。

观察器接收领域副本，不能直接改编辑器文档。异常观察器被停用并报告独立诊断，避免损害成功编辑及历史；属性事务失败仍回滚。

取舍：递归指纹便于解释，文档较大时需要考虑增量计算。
